# 拓竹 3D 打印耗材管理系统

## Bambu Lab Filament Manager

面向拓竹（Bambu Lab）3D 打印机用户的轻量级耗材库存与打印自动扣减系统，为社区开发的第三方开源工具。

支持多账号数据隔离、Web 端与桌面端耗材台账、3D 打印机虚拟 AMS 槽位映射、AMS 多色自动解析与续打拆分、多机位数据洞察、待买补货清单、打印损耗补扣及历史记录快照撤销等功能。

### 版本模式说明

* **网络联机版（推荐）**：包含 Web 端与 Windows 客户端，支持局域网或公网多机群、多设备协作同步。
* **单机离线版**：`BambuFilamentStudio_Standalone` 版本支持直接在 Windows 本地运行内置 SQLite 数据库，无需部署任何服务端即可使用全部设备管理、数据洞察及自动扣减功能（仅限单机本地使用，无法跨设备同步）。

# 🚀 服务端部署（联机版）

项目提供两种部署方式：

* **方案一：Linux + 1Panel + Docker Compose**
* **方案二：Windows 本地独立服务端**

---

## 方案一：Linux + 1Panel Docker Compose

### 1. 安装 MySQL

在 **1Panel → 应用商店** 安装 MySQL。

创建数据库：

```text
数据库名称：filament_db

```

记录以下信息：

* 数据库用户名
* 数据库密码
* 数据库名称

---

### 2. 上传项目源码

通过 1Panel 文件管理器上传 `backend`（包含 `main.py`）和 `frontend`（包含 `index.html`）文件夹。

推荐目录：

```text
/opt/bambu-filament-manager/
├── backend/
│   ├── main.py
│   └── requirements.txt
└── frontend/
    └── index.html

```

---

### 3. 创建 Docker Compose 编排

进入：

```text
1Panel → 容器 → 编排 → 创建编排

```

工作目录选择：

```text
/opt/bambu-filament-manager/

```

> ⚠️ **请先修改数据库用户名、数据库密码和 JWT 密钥，再启动容器。**

```yaml
services:
  filament-api:
    image: python:3.11-slim
    container_name: filament-api
    restart: always
    working_dir: /app
    volumes:
      - ./backend:/app
      - ./frontend:/app/frontend
    deploy:
      resources:
        limits:
          memory: 300M
    command: >
      bash -c "pip install --no-cache-dir -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
      && uvicorn main:app --host 0.0.0.0 --port 8000 --proxy-headers --forwarded-allow-ips='*'"
    environment:
      - DB_HOST=172.17.0.1
      - DB_PORT=3306
      - DB_USER=你的数据库用户名
      - DB_PASS=你的数据库密码
      - DB_NAME=filament_db
      - JWT_SECRET=请替换为随机长密钥
    ports:
      - "8000:8000"

```

保存并启动编排。启动成功后，后端 API 默认监听 `http://服务器IP:8000`。

---

### 4. 配置反向代理

#### 外网域名

在 1Panel 中进入 **网站 → 创建网站 → 反向代理**，代理目标填写 `[http://127.0.0.1:8000](http://127.0.0.1:8000)`。

#### 局域网访问

绑定到服务器局域网 IP（例如 `[http://192.168.1.100](http://192.168.1.100)`），代理目标填写 `[http://127.0.0.1:8000](http://127.0.0.1:8000)`。

> 💡 建议在路由器中为服务器设置 **静态 DHCP 租约**，避免 IP 变动导致客户端失联。

## 方案二：Windows 本地独立服务端

适合不想维护 Linux 服务器的用户。

### 1. 启动服务端

解压服务端至固定目录（如 `D:\BambuServer`），运行 `bambu_server.exe`。

选择网络监听模式：

```text
[1] 局域网/公网直连模式 (全网卡监听，推荐同 Wi-Fi 多设备访问)
[2] 本地独占安全模式   (仅本机 127.0.0.1 可访问)
[3] 自定义端口公网模式 (可指定端口)

```

### 2. 账号注册与快速授权

1. 浏览器打开 `[http://127.0.0.1:8000](http://127.0.0.1:8000)` 注册管理员账号并登录。
2. 打开 Windows 客户端进入 **⚙️ 服务设置**。
3. 点击 **🔑 一键登录获取**，输入网页注册的账号密码即可完成全自动安全绑定。

### 3. 数据备份与迁移

Windows 本地服务端的数据库文件为同级目录下的 `filament_db.db`。迁移电脑时只需关闭服务端，将 `bambu_server.exe` 与 `filament_db.db` 拷贝至新电脑运行即可。

# 💻 Windows 客户端使用指南

## 一、 联机版快速配置流程

```text
网页端注册登录 ──► 客户端输入账号密码一键获取 Key ──► 录入机台与耗材 ──► 开启切片监听

```

1. **服务配置**：进入 **⚙️ 服务设置**，填入扣减上报地址（如 `[http://127.0.0.1:8000/api/ingest/script-report](http://127.0.0.1:8000/api/ingest/script-report)`）和耗材台账地址（如 `[http://127.0.0.1:8000/api/ingest/script-filaments](http://127.0.0.1:8000/api/ingest/script-filaments)`），点击 **一键登录获取** 完成连接。
2. **机群与耗材建档**：在 **🖨️ 设备管理** 中添加打印机机型，在 **📦 耗材台账** 中录入耗材颜色、材质、单价与余量，并完成虚拟 AMS 挂载映射。
3. **开启监听**：确保 **切片打印自动监听** 开关处于开启状态。

---

## 二、 自动化切片扣减工作流

```text
Bambu Studio / OrcaSlicer 切片并发送打印
                 │
                 ▼
     Windows 客户端自动捕获切片盘
                 │
                 ▼
  弹出多色扣减窗口 (自动匹配机位与槽位)
                 │
  ┌──────────────┴──────────────┐
  ▼                             ▼
常规余量充足                存量不足触发续打
直接确认扣减             选择备用盘自动拆分扣减
                 │
                 ▼
     服务端 / 本地台账完成精确扣减

```

---

## 三、 单机离线版使用指南

对于完全没有网络连接或不需要服务端的用户，直接运行 `BambuFilamentStudio_Standalone_v3.1.0.exe`：

* 数据完全离线存储在本地同级目录的 `filaments.db`（SQLite）中。
* 自带设备管理、数据洞察、待买清单与多色自动切片监听扣减功能，零配置即开即用。

# 🧰 常见问题

## Q1：客户端连接不上服务器或报 401 Unauthorized？

1. 检查服务端是否正常运行且端口已放行。
2. 切换服务端（如从 Linux 换到 Windows 本地）后，由于数据库隔离，必须在客户端 **服务设置** 中重新点击 **🔑 一键登录获取** 重新换取当前服务端的专属 Key。

## Q2：添加打印机或打开数据洞察出现 500 错误？

请确保服务端已更新至 **v3.1.0**。新版本包含打印机表结构与字段热升级，旧版服务端缺少相关字段会导致接口报错。

## Q3：切片后客户端没有自动弹出扣减窗口？

1. 检查客户端内 **切片打印自动监听** 是否已开启。
2. 确认切片软件生成的文件中包含标准 G-code 耗材重量数据。
3. 检查当前切片盘总克重是否大于 0g。

## Q4：打印失败或产生额外耗料如何处理？

在台账对应耗材卡片上点击 **手动调整**，输入变动克重（减少或增加），并填写原因说明即可修正库存。

## Q5：误操作扣错了耗材克重如何撤销？

在耗材卡片点击 **历史**，找到对应任务记录点击 **撤销**，系统将自动基于历史快照精准恢复对应重量。
